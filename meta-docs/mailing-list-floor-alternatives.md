# Mailing list — six inclusion-rule alternatives

*All six tables use the 2026-08-27 Neon pull and the same pipeline as
`scripts/export_mailing_list.py`. Each table changes exactly one more rule, cumulatively:*

1. **Table 1 — as sent** ($200 five-year giving floor). 407 households. Rebuilt from the
   data and verified cell-by-cell against the sent email (`mailing-list-email-draft.md`).
2. **Table 2** — five-year floor dropped to $150. 422 households.
3. **Table 3** — five-year floor dropped to $100. 467 households.
4. **Table 4** — Table 3 plus **all** new accounts opened in FY25–26 (the $100
   registration floor on Judy's new-accounts list is dropped). 662 households.
5. **Table 5** — Table 4 with the engaged-non-donor spending threshold dropped from $500
   to $250. 748 households.
6. **Table 6** — Table 5 plus the 32 non-Neon Fort Salem Theater supporters we have
   mailing addresses for. 780 households.

"Gave to the 2025 campaign" = received last fall's appeal and gave $10 or more to the
Annual Fund Drive between October 1, 2025 and January 31, 2026. Rows 3 and 4 show "—" in
the campaign column; any campaign-window gifts those households made (they did not count
as campaign givers) sit in their "rest of FY26" figure.
